MAHBOOB AHMED — DARK PORTFOLIO WEBSITE

How to view:
1. Extract this ZIP file.
2. Open the mahboob_portfolio folder.
3. Double-click index.html to open the portfolio in your browser.

Files:
- index.html: portfolio content and page structure
- styles.css: dark theme, layout, and responsive styling
- assets/: profile image extracted from the provided CV (if available)

To publish:
Upload the extracted files to a static hosting service. Keep index.html, styles.css, and the assets folder together.

Contact details and experience are based on the CV provided. You can edit index.html to update any information.
